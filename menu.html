Okta Rule Builder (ORB)
?

Enhances Okta with these features:

  • Edit Okta Expression Language in a visual logic-builder UI
  • Run real-time tests against your expresion and see which users match your expression.

Usage

  1. Login to Okta or Okta Admin.
  2. Navigate to Groups > Rules > Add Rule OR View/Edit an existing Rule
  3. Click "Open in Rule BUilder" to edit your expression in a visual UI using AND/OR expressions.
  4. Click "Preview OEL Rule" to run real-time tests against your expresion and see which users match your expression.

Bugs or Feedback?

The source is available on GitHub, please create an Issue and I promise to review it!
