Release Notes v0.9

  • Added App and Group membership Export functions.
  • Improved on the "View Rule" function when looking at a group's users populated by Rule.

Enhances Okta with these features:

  • Edit Okta Expression Language in a visual logic-builder UI
  • Run real-time tests against your expression and see which users match your expression.
  • View the rule expression directly on a Group populated via Rule with a simple button click

Usage

  1. Login to Okta or Okta Admin.
  2. Navigate to Groups > Rules > Add Rule OR View/Edit an existing Rule
  3. Click "Open in Rule Builder" to edit your expression in a visual UI using AND/OR expressions.
  4. Click "Preview OEL Rule" to run real-time tests against your expression and see which users match your expression.
