# Okta Group Rule Builder — Chrome / Edge Extension

Simple React app, packaged as a
Manifest V3 extension that opens in its own full browser tab when you click the
toolbar icon.

## Build (one time)

Requires Node.js (18+) and npm.

```bash
cd okta-ext
npm run build      # or: bash build.sh
```

This downloads React into `vendor/` and compiles `app.jsx` -> `app.js`.

## Install

1. Open `chrome://extensions` (or `edge://extensions`)
2. Turn on **Developer mode** (top-right)
3. Click **Load unpacked** and select this `okta-ext` folder
4. Click the extension's toolbar icon — the builder opens in a new tab

## Files

| File | Purpose |
|------|---------|
| `manifest.json` | MV3 manifest |
| `background.js` | Opens the builder in a full tab on icon click |
| `index.html` | Page shell; loads local React + `app.js` |
| `app.jsx` | The React app (source you edit) |
| `app.js` | Compiled output (generated by build) |
| `vendor/` | Local React + ReactDOM (generated by build) |
| `icons/` | Toolbar / store icons |
| `build.sh` / `package.json` | Build tooling |

## Replacing the icons

`icons/icon16.png`, `icon48.png`, `icon128.png` are plain placeholder squares.
Swap in your own PNGs at those sizes if you want branding.
